NUESTRA NOCHE — beso + Silverado ❤️

1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html.
3. Puedes usar Live Server para verlo en el navegador.
4. Pulsa "Entrar a nuestro momento".

La pantalla está pensada como una sola escena cinematográfica:
- primero aparece la pareja y la Silverado roja;
- se muestra el momento del beso;
- después cambia el mensaje a "nos vamos juntos";
- el encuadre hace un pequeño zoom para dar sensación de despedida/partida.

La imagen de la escena está en assets/escena-pixel.png.
